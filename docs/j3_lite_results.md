# J3-lite 结果：多候选关联评价与三态决策

日期：2026-11-05 | 运行：`runs/j3_lite/`（串行 setsid driver），
阈值 **train-only 校准**（FPR≤5% 高阈 + 正样本 P10 低阈），test 只评估。

## 1. 多候选关联评价（任务 §七——避免把 Pair Accuracy 当 MOT 性能）

**TEST 集 388 个竞争集**（每 anchor 全部候选，含正主与真实共现竞争者）：

| 指标 | 值 | 解读 |
|---|---|---|
| Top-1 Identity Accuracy — **J0 kin 排序** | **0.807** | 运动学外推排序在候选间区分力强 |
| Top-1 Identity Accuracy — J1 cos 排序 | 0.598 | **外观排序显著弱于位置排序** |
| 正确候选不在候选集比例 | **0.0** | 竞争集覆盖完整（无真主缺失） |
| 多候选歧义率（top-2 cos 差 <0.05） | 0.531 | 近半竞争集外观难分 |
| uncertain 带内真主占比 | **1.0** | 带内全部是真配对（拒识带没有藏错误，但也说明错误候选的 cos 分布两极） |

**核心诚实发现**：pair 级的 precision 0.891（严格阈值）**不能外推到
多候选场景**（accept precision 0.691）——竞争者是时空真实共现的
行人，其 cos 整体偏高（同行/近旁），被 thr_hi=0.7584 大量放行。
任务书 §七的预警被实测证实。

## 2. J3-lite 三态决策（任务 §八）

规则：accept = top-1(cos) ∧ cos≥0.7584 ∧ kin≤0.15；reject =
cos<0.5853 或 kin>0.30；其余 uncertain。阈值均 train-only
（高阈 FPR 4.97%/TPR 53.2% 于训练候选；低阈=正主 P10）。

**TEST**：coverage（accept 率）0.626、**accept 内错误身份率 0.309**
（precision 0.691）、reject 0.070、undetermined 0.304。
防刷指标：uncertain 带真主占比 1.0（带内无错误候选——**拒识带
未隐藏错误，但也没有拦截到错误**：错误竞争者主要被 cos 阈值
直接放行）。

## 3. 风险-覆盖率曲线（§八核心验证）

**问题 6 的诚实回答：部分成立，但形态错误**——
1. J3-lite 相对 **J1-无拒识**（top1 全接受：coverage 1.0 /
   precision 0.598）在 coverage 0.63 下 precision +9pp（0.598→0.691）；
2. 但 **J0-kin 排序的潜力（top1 0.807）未被利用**——当前 accept 用
   cos 排序、kin 仅作 0.15 门（不参与排序）。固定覆盖下的错误
   选择率 0.309 仍高于 kin 排序可达水平；
3. **缺失对照**：J0-kin-三态（kin 排序 + kin 阈值拒识）未运行——
   完整对照需补（列为下一步，未运行如实标注）；
4. **结构性教训**：正确形态应为 **联合排序**（kin∧cos 融合分数
   决定 top-1）+ cos 阈值拒识——外观的价值在"该不该信"（阈值），
   位置的价值在"选谁"（排序）。这与 E1 的 actor_binding
   （kin 排序 + 消歧）结构一致，J 特征应作为第二证据列接入
   而非替换排序主键。

## 结论（多候选 vs pair 级的方法学分野）

pair 级（J1.1 审计）与多候选（本节）给出**互补而非矛盾**的结论：
阈值能力（cos 严格阈值）与排序能力（kin 外推）各擅其场；
把两者压成单一"外观关联更好/更差"的叙述都会失真。

## 附录 A：遮挡采样三策略（§五，runs/j1_1_audited）

500 对（train 200 / test 300，严格 FPR≤5% 校准，各策略独立缓存）：

| 策略 | thr | train TPR | test fused FPR | fused prec | fused miss |
|---|---|---|---|---|---|
| A all | 0.8378 | 0.326 | 0.038 | 0.897 | 0.634 |
| **B prefer_visible（修正版）** | 0.8564 | 0.217 | **0.019** | **0.933** | 0.704 |
| C weighted | 0.8415 | 0.283 | 0.038 | 0.889 | 0.662 |

**判读**：
1. B 修正后与 A 产生真实差异（初版 `occ<2` 与 A 逐值相同——D8）；
2. **固定低 FPR 下 B 最优**（precision 0.933/FPR 1.9%）——可见帧
   特征更纯净，"接受"建立在最高质量证据上（与三态哲学一致）；
   代价 TPR 最低（0.217）；
3. C 加权无额外收益（介于 A/B 之间不占优）——**观测质量权重的
   温和形式不引入信息**；
4. 数据事实：500 对含 occ=1 帧 28.5%（occ=2 为 0，插值标注本性）。

**结论（问题 4）**：遮挡采样修正后**生效**；推荐 B 为
accept 路径的默认构造。
