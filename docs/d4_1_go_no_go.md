## 2. 最终判定：**CONDITIONAL-GO**

**GO 的部分**：
- D4 联合排序（Top-1 0.700 > 0.650）——判别式预测特征确实
  能改善候选排序（此前 B0/B4 从未参与排序）；
- 固定覆盖率下 D4 联合不劣于基线（wrong_50 = A1）。

**CONDITION**：
- G1 未过静态基线（M_hard 0.0212 < 0.0339）——不宣称超越静态；
- 后续需更大训练量 + 更强架构（当前 240 anchor/53 源）。

**NO-GO 的部分**：
- 不宣称"超越静态基线"；
- 不宣称"选择性关联改善"（wrong_50 = A1，未改善）。

## 3. 与历史负结果的关系

三轮训练（v1 0.110 → v2.2 0.189 → D4 0.212）的 G1 均未过静态
基线，但 G2（排序）首次通过——**判别式目标在排序维度有真实
增量，这是此前负结果无法看到的能力**。这为后续研究提供了
方向依据：不是继续提高未来特征回归精度，而是让判别式目标
在排序任务上发挥作用。
