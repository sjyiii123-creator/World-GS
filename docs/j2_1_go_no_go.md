## 2. 验收十问速答

1. 原 J2 区分间距是否存在错误负样本？**是**（42 对同身份误标，
   影响 <0.002——方向已修复，量级可忽略）；
2. 修正后 J1/J2 间距？J1 **0.256** / J2-C **0.111** / J2-D 0.108
   （hard 负样本上 J2-C 0.686 vs J1 0.557）；
3. 候选目标独立使用自己的时间间隔？**是**（逐候选 delta + 无效
   → unknown；本床数值不变系时间聚集所致）；
4. 真实源视频数/Actor 数？train **53 源/160 actor**、val 15/43、
   expl 8/38、final 2/2（我此前口头源数有误，已勘误）；
5. 负结果公平复核后是否成立？**成立**（三重证据一致）；
6. JEPA 模块可独立开关？**是**（LatentEvidenceSwitch，
   off-by-default）；
7. 关闭 J2 时旧验证器完全一致？**是**（links 原样返回断言 +
   legacy 套件 55 项全绿）；
8. 仍存在未来信息泄漏？**已知路径全部消除**（推理输入无未来；
   竞争集时间独立；因果守卫 + 双通道核验 0 违规）；
9. 残差 + 困难负样本值得正式训练？**设计值得、时机未到**
   （见 §3 条件）；
10. 进入事件级实验缺什么？①E2 人工事件真值（20 行标注 +
    event_protocol 复核）；②J2 v2 在全量数据 + 修正协议下重获
    正区分间距；③冲突样本隔离协议执行。

## 3. 最终判定：**CONDITIONAL-GO**

**GO 的部分**（可立即执行）：
- J2 v2 设计 B（Static Residual）在**全量 A 正对**上训练
  （单一变量：残差参数化 vs v1 的直接预测；判定标准 =
  J2.1 修正协议的区分间距与 A3 竞争集对照）；
- latent_world_state 模块保持 off 状态随主线发布（零侵入）。

**CONDITION（启动训练前必须满足）**：
1. 全量 A 正对数据集构建 + 六步梯（含过拟合检查）；
2. 训练监控三件套就位（预测方差 / 均值相似度 / 区分间距早停）。

**NO-GO 的部分**（维持停止）：
- C（hard-negative ranking）与 D（运动状态）——待 B 显示残差
  有效后逐项消融（不得一次全加）；
- V-JEPA 2.1 对照（前置未成立）；
- 事件级实验（双门槛未满足——人工真值 + J2 有效增量）。

## 4. 下一轮最小闭环（建议）

1. 全量正对数据（~2,600 独立单元）构建 + preflight；
2. J2 v2-B 训练（残差 + 区分间距早停）；
3. 同协议重评（Gate 0/1 修正协议）：间距 ≥ 静态基线的 80%
   （预注册阈值）才进入 C 的消融；
4. 人工真值标注（与训练并行——事件级的独立关键路径）。
