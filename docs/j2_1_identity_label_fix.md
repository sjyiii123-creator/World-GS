# J2.1 身份标签修复报告（Gate 0）

日期：2026-11-05 | 重评：`runs/j2_1_reeval/pair_reeval.json`
（原始 `j2_ablation.json` 只读保留）；回归 12/12

## 1. 确认的缺陷

旧 `val_negative_discrimination` 以矩阵**非对角线**为"不同 actor"——
同一 actor 的**多条序列**（val 中 14 个 actor 有多序列）互为"负样本"。

**实测影响量**：val 60 序列的非对角 3,540 对中 **42 对（1.2%）为
同身份误标**——同身份 cos 偏高 → 负均值被抬高 → **旧区分间距被
低估**（方向：修正后间距应变大）。

## 2. 修复协议（`latent_world_state/association_evidence.py`）

- 身份关系 = **(source_video_id, actor_id)**——同 actor 跨序列为
  SAME；**不同视频中相同数字 ID 是不同行人**（任务 §二.4）；
- 负样本分解：**hard**（同源不同 actor=同场景共现者）与
  **easy**（跨源）分开报告；
- 回归测试：重复 actor 标 SAME、跨视频同 ID 标 DIFFERENT、
  hard/easy 划分完整性（12/12）。

exploratory_test 同趋势（J1 0.251 / J2-C 0.092）。

## 4. 结论

1. **身份标签错误实际影响 <0.002**（42/3540 对）——数值上可忽略，
   但协议修复是正确性义务（且 hard/easy 分解是新信息）；
2. **负结果在公平复核后成立**：J2-C/D 区分间距（~0.11）仍显著
   低于静态（~0.26）；
3. **新发现**：同源 hard negatives 的 cos 明显更高（J1 0.557 vs
   混合 0.481；J2-C 0.686）——**预测特征在真实同场景竞争者上
   更弱**，加固了"预测特征共性化"的诊断。
