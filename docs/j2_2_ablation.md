## 2. 两个单变量效应（均真实）

- **残差参数化**（B2−B1 / B4−B3）：+0.044 / +0.030——正交于数据
  规模的稳定增益；
- **数据扩充**（B3−B1 / B4−B2）：+0.049 / +0.035——独立源/actor
  ×2.5（53→81 源、160→402 actor）的真实收益。

## 3. 静态基线天花板（负结果核心）

B4（0.189）距 B0（0.249）仍差 0.06——**残差+扩充的正确方向
未足以翻越静态基线**。缺口归因（区分已证实与推测）：

- **已证实**：共性化未消除（pred-batchmean 0.853、预测方差
  0.026——GRU 仍输出低多样性特征）；
- **推测（未验证）**：cos-only 目标不优化判别边界——hard-negative
  ranking（设计 C）正对此缺口，**这是进入 C 消融的直接证据依据**。

## 4. 预算与缺口声明

全部 5 组均秒级训练（0.04GB VRAM）——无预算问题；唯一缺口是
**全量 1,245 独立 anchor 中 445 未抽样**（特征提取预算，协议已
固化可扩展）——B3/B4 的"扩充"如实标注为 800/1245 抽样。
