# J2.3.2a 距离校准器修复（P0-A）

日期：2026-11-05 | 独立确认（数值精确复现）

## 1. 缺陷确认

`calibrate_lower_is_better` 从小到大扫描唯一负值，**取第一个
满足 FPR 约束的阈值就停止**——返回最小可行阈值：
- 旧 thr=0.0036 / FPR 0.17% / TPR 22.08%
- 同数据**最大可行阈值 0.0183 / FPR 4.92% / TPR 71.25%**
  （39 个可行阈值中取了最小——过度保守 3.2 倍 TPR 损失）

## 2. 修复

唯一值扫描 → 收集**全部**可行阈值 → 取**最大**（max-TPR-under-FPR
约束）。ties/零阈值/空样本/异常值处理不变（唯一值扫描天然处理
ties；round 不再破坏 FPR——report 携带实测值）。

## 3. 修复后实测（新 2a 数据，train Tier-1 负样本 1,095 条）

| 指标 | 旧（min-feasible） | **新（max-feasible）** |
|---|---|---|
| threshold | 0.0036 | **0.0188** |
| train FPR | 0.17% | **4.93%** |
| train TPR | 22.08% | **50.42%** |
| val A1 coverage | 0.15 | **0.52** |
| expl A1 coverage | 0.16 | **0.65** |

TPR 仍非 71%（候选集合因 P0-B 修复而变化——旧数字基于 0.6s
候选；新 1.0s 候选更难）。**FPR ≤ 5% 目标严格满足**。

## 4. 边界声明

**训练集经验 FPR ≤ 5% 不自动保证未知场景 FPR ≤ 5%**——
分布漂移下需重新校准（统计保证仅覆盖校准集分布）。
训练/验证/探索测试三层 FPR 已分别落盘（baseline_aligned.json）。

## 5. 回归测试

合成数据：存在更大可行阈值时校准器不得提前返回过小阈值
（selftest 自动覆盖——max 逻辑由 `feasible` 列表语义保证）。
