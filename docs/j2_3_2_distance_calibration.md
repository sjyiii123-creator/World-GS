# J2.3.2 距离校准修复（P0-B）

日期：2026-11-05 | 独立确认：94.38% 负候选接受率 + 正确方向阈值
应 ≈0.023（agent 复算）；修复实测 FPR 0.17%

## 1. 缺陷确认（方向反转）

`calibrate_threshold`（高分校准器：约束负样本分数 ≥ t 的比例）
被直接用于 **kin 距离**（低分优）——阈值落在负样本距离的 ~95
分位：**旧 kin_thr=0.6517 使训练负候选 94.38%（1629/1726）满足
接受**（agent 独立复现 0.943801）。A1 的 val coverage=1.0、
no-match FA=1.0 均为该错误的下游症状。

## 2. 修复（calibrate_lower_is_better）

新函数（latent_association.py）：距离语义——接受 = score ≤ t；
**FPR = frac(负样本 ≤ t) ≤ target**（唯一值扫描、floor 计数、
无回退、报告实测 FPR/TPR/覆盖率）。测试：合成距离（FPR 恰 5%、
TPR 100%、零阈值有效、ties 处理、不测试集调参、失败不放宽）。

## 3. 修复后实测

**kin_thr = 0.0036**（train 纯 Tier-1 负样本校准）：
- 实测 **FPR 0.17%**（≤5% ✓——极保守：Tier-1 是强竞争者，
  低阈值正确反映"距离证据在高竞争下不可信"）；
- TPR 22.1%（低——**FPR≤5% 与高 TPR 在纯 Tier-1 上不可兼得**
  （如实声明，与 J1.1 的外观 tradeoff 同构））；
- A1 coverage val 0.15 / expl 0.16（低覆盖是校准正确性的直接
  推论——不再用错方向阈值虚开接受门）。

## 4. 语义边界（任务 §五.6）

**Pair 级 FPR ≠ 多候选错误身份放行风险**——两者分母不同
（负样本数 vs 竞争集数）；报告分别列出，不做等式转换。
