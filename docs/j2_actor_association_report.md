## 2. 结论：预测证据无增量，联合排序有害（负结果）

1. **A3**：pred_cos 阈值 0.8018 把 85% 竞争集推入 uncertain
   （coverage 0.72→0.15）而错误接受率**没有改善**（0.119→0.167
   反升）——预测证据只增加保守性不增加准确性；
2. **JOINT 联合排序崩溃**（top1 0.805→0.415）：pred_cos 的
   z 分数与 kin 的 z 分数等权——无区分力的证据列**污染排序**
   （消融已证预测特征共性化 gap 0.11 vs 静态 0.26）；
3. no-match 假接受：A3 降到 0.049（唯一改善项——但代价是
   coverage 0.15，实质是"几乎全拒"）——按固定覆盖率解读不成立；
4. **遵守的边界**（任务 §六）：预测相似从未单独合并 Track ID；
   多候选相近进入 Uncertain（歧义带 0.5σ）；预测到目标存在
   ≠ 观察到目标——本报告的全部关联证据均不进入事件判定。

## 3. 唯一推荐的融合形态（当前证据下）

**A1 独立运行**（kin 排序 + kin 拒识 + no-match 绝对分数门——
A1 的 no-match FA 0.293 是下一改进目标）；J2 证据列在预测器
重新设计（全量数据 + 排序损失）并重新通过消融判据前**不接入**。
