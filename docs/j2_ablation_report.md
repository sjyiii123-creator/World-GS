# J2 消融报告（阶段 5）——含负结果

日期：2026-11-05 | 运行：`src/run_j2_association.py`（消融段）→
`runs/j2_experimental/j2_ablation.json` | 评估：v2 val split（60 序列，
源级隔离），同协议对照

## 1. 五方法对照（预测目标特征；判定指标=区分间距）

| 方法 | cos(pred,target) | **same-diff actor 区分间距** | gap 分层 cos（0.5/1.0/1.5s） |
|---|---|---|---|
| J1 静态（anchor vs 目标） | 0.741 | **0.257** | 0.767/0.739/0.707 |
| J2-A 末帧即预测 | 0.741 | **0.257**（与 J1 同——静态语义等价） | 同上 |
| J2-B 历史均值 | 0.720 | 0.240 | 0.727/0.728/0.697 |
| J2-C GRU | 0.730 | **0.110** | 0.731/0.743/0.711 |
| J2-D GRU+2D 速度 | 0.731 | 0.107 | 0.734/0.741/0.713 |

## 2. 结论：J2 v1 无增量（负结果，如实报告）

1. **预测质量无提升**：J2-C/D 的 cos-to-target（0.730/0.731）
   **低于**简单静态末帧（0.741）——GRU 没有学到超越"不变性
   假设"的漂移先验；
2. **区分力减半**（0.110 vs 0.257）：预测特征趋于"共性化"——
   对所有 actor 的未来特征都给出中等相似度（训练目标的同 actor
   未来本身漂移大，小数据下模型收敛到均值化解）；
3. J2-D 的 2D 速度无改善（0.107 vs 0.110）——运动信息已被
   kinematic 排序主线覆盖（bbox 速度非 action command，遵守
   任务边界）；
4. **长 gap 分层**：所有方法 cos 随 gap 衰减（0.74→0.71），
   预测器未兑现"补偿长 gap 漂移"的假设（J2 增量假设证伪——
   至少在 240 训练序列量级下）。

## 3. 失败归因（区分已证实的与推测的）

**已证实**：小训练量（240 序列/~几十独立 actor）下，逐 actor
未来特征的可预测成分有限；共性解是损失面最优。
**推测（未验证）**：a) 全量 A 正对（7,920）训练可能改善；
b) 排序/对比目标（任务 §五的后续项——hard-negative margin）
   可直接优化区分间距——本轮按纪律未启用（"只有前述实验显示
   不足时再考虑"——现在不足已显示，列为下一轮候选而非本轮补丁）。

见 j2_actor_association_report——结果同样为负/中性）。
