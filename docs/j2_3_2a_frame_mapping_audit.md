## 2. 0037 的映射定性（延续 E2.1 结论）

- 窗口声明 150 帧但视频实际 300 帧（2×）——**声明标签失实**；
- 映射 `xml − f0` 对 0037 **正确**（f0=0 → clip 帧号=XML 帧号，
  候选 [75,131] 在 300 帧范围内）；
- **影响**：0037 的候选/特征全部有效（帧号直接命中）；
  唯一风险是 anchor_end 声明（f_end=149 vs 实际 299）——
  我们的 anchor 历史取自 XML 因果帧 ≤ f_end，与视频一致性
  由 IoU 核验背书（E2.1）；
- **结论**：无候选因 0037 异常被污染；**声明修正留给数据集层**。
