## 3. 统计力声明（诚实边界）

1. **final_test 仅 2 源/12 序列**——不得作为有充分统计力的最终
   泛化实验（方向性 sanity ONLY）；真正独立的最终测试需在协议
   冻结后预留**新的源不相交场景**（GATES 文档既有要求）；
2. exploratory_test 的 8 源全部被 J 系列查看过——保留探索性标记，
   不冒充独立测试；
3. **有效独立训练单元 ≈ 160 个 actor / 53 个源**（240 序列中 80
   条来自重复 actor）——这是"训练数据不足"结论的量化基础；
4. 本轮未做任何重新划分——所有数字来自既有 v2 数据的只读统计。
