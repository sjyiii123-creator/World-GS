# JEPA 方法分析与创新性核查（J 系列前置）

日期：2026-11-05 | 核查对象：V-JEPA 2 / 2.1、GOT-JEPA（TCSVT 2026）、
DrivingGen（ICLR 2026）——官方仓库与论文页联网核实。

---

## 1. 已有 JEPA 研究解决了什么（核查事实）

### V-JEPA 2 / 2.1（facebookresearch/vjepa2）

- **本体**：掩码潜在特征预测的自监督视频表征（ViT-L/H/g，300M–1B；
  2.1 新增 dense predictive loss + 深层自监督 + 时序一致 dense 特征，
  ViT-B 80M 起步）；
- **已解决**：视频理解探针（SSv2 77.3、Diving48 90.2）、动作预期
  （EK100 39.7% 超 prior best 12pp）、动作条件世界模型（V-JEPA 2-AC
  机器人操控，零环境标定 reach 100%）；
- **明确不涉及**：**多目标跟踪与身份关联无任何 benchmark/声明**；
  最近的 2.1 "temporally consistent dense features" 是特征质量主张
  （PCA 可视化），非跟踪任务。

### GOT-JEPA（arXiv:2602.14771，TCSVT 2026）

- **GOT = Generic Object Tracking（单目标跟踪）**，非 goal-oriented、
  非生成式；
- **已解决**：跟踪器对训练目标过拟合 + 粗粒度遮挡处理——JEPA 式
  "从损坏帧预测跟踪模型"（teacher-student）+ OccuSolver 细粒度可见性
  估计；七个跟踪基准的泛化/鲁棒提升；
- **明确不涉及**：**MOT、跨遮挡间隙的身份重关联、驾驶世界模型评价**
  均无。

### DrivingGen（ICLR 2026，本地源码已审）

- 评价对象为整段质量/轨迹/agent 一致性；Agent Missing 用 7B VLM 裁决
  （本机不可行）；**无任何潜在表征时序预测用于关联**；无事件级协议。

## 2. World-GS 的贡献候选定位（为什么不是重复通用跟踪）

| 维度 | 通用 JEPA 跟踪研究 | World-GS J 系列 |
|---|---|---|
| 问题 | 表征预训练/单目标跟踪鲁棒性 | **跨间隙身份重关联的证据质量**——为下游事件验证服务 |
| 数据 | 大规模视频/跟踪基准 | 带官方身份真值的 JAAD 行人（211 窗口）+ 生成视频验证域 |
| 输出 | 特征/跟踪器 | **关联证据（含歧义）→ 事件三态判定 → 可信准入** |
| 评价指标 | 探针精度/跟踪 MOTA 类 | 关联准确性 + **错误合并率 → 事件验证的 IAR/VRR 传导** |
| 闭环 | 无下游准入 | evidence → actor_binding → crossing_evidence → adjudicate |

**核心差异声明**：J 系列不是"又一个跟踪器"，而是把**冻结通用表征的
关联证据**接入**安全关键事件验证链**（关联错误如何转化为 Invalid 误报
已有 E1 实证：0016 假 INVALID），并以**不确定性感知准入**为最终出口。
该链路在三个被核查对象中均不存在。

**潜在时序关联对事件验证的价值假设**（本轮 J1 检验的正是第一环）：
运动学关联在 J0 上错误合并率 18.2%——这些错误合并会直接制造
"错误身份满足事件"或"真 actor 断链 → 假消失"。外观/时序特征若把
错误合并率压到 <5%（预注册判据），事件验证的误放行/误拦截才可能
实质性改善——这是 J 系列存在的**唯一理由**，不成立则不进入 J2。

## 3. V-JEPA 2.1 是否值得作为下一组对照？

**结论：列为可选 J1'，不阻塞主线。**
- 支持：2.1 的 dense 时序一致特征理论上更抗遮挡（token 级时序 vs
  我们的帧级 CLS 平均），可替换 encoder 做同协议消融；
- 反对：最小 80M（ViT-B/16@384px）vs dinov2-small 22M——显存/推理
  成本 ×4 以上；且其优势主张在"特征质量"，未在身份重关联任务上
  验证过；
- 判据（预注册）：若 J1 显示 dinov2-small 的 same/diff 余弦分离度
  不足（AUC<0.8），再引入 2.1 ViT-B 对照。

## 4. GOT-JEPA 的两个可借鉴点（记录，不引入）

1. **"预测跟踪模型"思想**：J2 的目标选择备选——预测关联参数/
   可见性而非未来特征（我们的 latent_predictor 保持特征预测主线，
   参数预测列为设计分支）；
2. **OccuSolver 可见性估计**：与我们 segment_feature 的遮挡感知采样
  （skip_occluded）同构——其迭代精化可作 J3 的不确定性升级路径。

## 5. 驾驶世界模型评价侧的定位

DrivingGen（VLM 裁决、全场平均）与 World-GS（证据链、事件级、三态）
的评价哲学差异已在 `drivinggen_baseline_analysis.md` 论证；J 系列补充
的正是 DrivingGen 完全没有的"关联证据质量"层。
