- **泄漏审计违规 = 0**（逐记录核验 max(anchor frame) ≤ t ∧

## 2. 特征空间健康（塌缩与可区分性）——实测

- **有效秩 383/384**（SVD 1% 截断）——**无特征塌缩**（"OK"）；
- same-pair cos（anchor 末帧 vs 真实未来）= **0.757 ± 0.102**——
  分布连续无双峰退化；
- **负样本可区分性**由 J1.1 校准报告背书（same 0.78 vs diff 0.59，
  严格阈值 FPR 4.93%）——J2 训练不会退化为"全相似"目标。

## 3. 契约（防泄漏与防误用）

- 预测器输入 = **t 时刻之前的逐帧冻结特征序列**（API 形状测试固化：
  forward() 无未来参数）；
- 未来特征仅作训练目标（loss 的 target 位置）；
- **预测误差只是证据**（J3 的拒识信号），不得单独判 Invalid；
- 预测状态不得当作实际视觉观测（下游 crossing_evidence 仍消费
  真实检测）。

## 4. 触发门与训练配置（提议）

epoch 40 / batch 64 / lr 3e-4、**val 按源视频划分**（防泄漏）。

## 5. J2 相比冻结 DINOv2 的潜在增量（问题 8 的回答基础）

外观漂移实测（J1 数据）：same-identity cos 随 gap 单调衰减
（0.825/0.781/0.756 @gap 15/30/45）——**anchor 特征直配在长 gap
退化**。J2 预测的是"t+Δ 时刻的特征"，与实际候选特征比对——
若预测器学到的漂移先验优于"锚特征冻结"，长 gap 的召回可提升
（不增加 FPR——接受门限不变）。**这是假设，未验证**；
J2 训练后才可测（与 J1 同协议对照）。
