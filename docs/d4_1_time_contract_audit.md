# D4.1 时间契约审计

日期：2026-11-06 | 修复：每候选独立 delta_s

## 1. 缺陷确认

旧 D4 评价用 `tc["delta_s"]`（正确候选的 delta）对**全部候选**复用——
时间信息泄漏：其他候选的预测时刻由正确身份标签决定。

## 2. 修复

`run_d4_1_reevaluation.py`：每候选使用 `c["delta_s"]`（自身时间）。

## 3. 实测影响

- 3,513 候选中 **182 条（5.2%）** 的 delta_s 与其真主不同——
  这些候选在旧代码中被错误地赋予了真主的时间；
- 修复后每候选独立 delta——训练/评价语义一致（无需重训，
  因 checkpoint 的 forward 接口为 (history, delta) 通用形式）。
