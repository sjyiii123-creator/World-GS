## 1. 十二问回答（任务 §十二）

1. **关联模块边界漏洞修复？** 是——`or 9.9` 零误差 bug、单候选
   无证据自动放行、写死 margin 三处全部修复 + sidecar 副本化；
   10 项边界回归（零误差/None/NaN/Inf/负数/单候选/同分/全无效/
   margin 参数化/冻结不突变）全过；
2. **扩充数据源泄漏？** 否——25 个 val/expl/final 源排除（构造 +
   加载分离双核验），零重新划分；
3. **新增独立源/Actor？** 池 +29 源/+284 actor（82/444 vs 53/160）；
   实际训练抽样 81 源/402 actor（800/1,245，预算声明如实）；
4. **残差严格支持静态回退？** 是——零残差 == normalize(z_last)
   精确成立（1e-6），退化解即基线；
5. **B4 优于静态？** **否**（0.189 < 0.249——主负结果维持）；
6. **优于原始 GRU？** **是**（B4 0.189 > B3 0.159 > B1 0.110——
   残差 +0.030~0.044 稳定增益；数据扩充 +0.035~0.049 独立增益）；
7. **多候选关联改善？** 否（top1 恒 0.805）；
8. **固定覆盖率错误选择率下降？** 否（A3 表面优势=A1 行为退化，
   如实报告）；
9. **特征共性化？** 减轻未消除（pred-batchmean 0.853 vs v1
   0.906；方差 0.026 仍低）；
10. **允许进入 C（hard-negative 消融）？** **有条件允许**——
    缺口 0.06（B4→B0）+ 共性化残留 + cos-only 不优化判别边界，
    三项证据都指向 C 的直接相关性（预注册：以 B4 为基线、
    val 区分间距 > B4 才进入 D）；
11. **事件级条件？** 未具备——E2 人工真值未完成 + J2 无超越
    静态的增量（双门槛维持）。

## 2. 最终判定：**CONDITIONAL-GO**

**GO（下一轮可执行）**：
- C 消融（Residual + Hard-Negative Ranking）——在 B4 架构上单变量
  加排序损失，同协议对照 B4/B0；判据预注册：val 区分间距
  **> 0.249（静态基线）** 才判方法有效（不是 > B4）；
- 全量 1,245 anchor 补齐（纯特征提取增量运行，协议已固化）。

**CONDITION**：C 的 hard-negative 采样需核实真实时间重叠竞争
（任务 §五.5——同源不同身份 ≠ 同时出现，需窗口重叠证据过滤）。

**NO-GO**：
- D（运动状态）——待 C 结果（单变量纪律）；
- 事件级实验（双门槛未满足）；
- V-JEPA 2.1 对照。

## 3. 负结果档案（按 §八纪律保留）

J2 v2-B（残差+扩充）**未超越静态基线**（0.189 vs 0.249）且
关联无增量——这是第二轮保留的负结果（v1 直接预测 0.110 →
v2 残差 0.189：方向正确、幅度不足）。论文可诚实报告为：
"残差参数化与数据扩充各自带来稳定但不足以翻越静态基线的改善；
判别目标（C）是剩余缺口的最小候选"。
