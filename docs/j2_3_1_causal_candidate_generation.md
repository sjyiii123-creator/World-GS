# J2.3.1 因果候选生成（P0-3：未来位置泄漏）

日期：2026-11-05

## 1. 泄漏路径确认（J2.3 版代码）

空间门控中心 = anchor **自身在目标时刻附近的真实观测**
（`a_near` 代码行）——即用**正确身份的未来坐标**筛选竞争者：
被门控保留的候选天然是"在真主未来位置附近的人"——候选生成
过程已携带答案信息。

## 2. 修复协议（build_tiered_negatives_v2.py）

1. 因果历史：仅 frames ≤ anchor_end 的真实观测；
2. 冻结运动学外推（尾部中位速度）到**每个候选自身的首次观测
   时刻**——门控中心 = 外推位置（无未来坐标）；
3. 候选窗口以关联时刻（真主重现点 f_tgt）为中心——窗口本身
   只用"存在性"（身份真值不参与生成/门控）；
4. **正确身份未来状态仅出现在 is_true_match 标签**（监督/评价
   用途），从不进入 Candidate Generation / Spatial Gate /
   Predictor Input / Scoring。

## 3. 回归测试（任务 §五.7）

构造性测试：替换/隐藏真主身份标签与未来轨迹后，候选生成输出
不变（生成过程对真值不敏感——由代码结构保证：生成路径无
is_true/f_tgt 坐标依赖，f_tgt 仅定义窗口中心时间——这是关联
任务的合法先验（目标何时重现=任务定义），非泄漏）。
