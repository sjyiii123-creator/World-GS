# J2.3.2 Tier-1 Margin 重校准（P0-C）

日期：2026-11-05 | 独立确认：959 Tier-2 混入（val 46/60 anchor）
+ Tier-2 占旧 M_hard 负集 31.9%（只能压低 margin）

## 1. 缺陷确认

旧 `m_hard` 以 `kin ≤ kin_thr(0.6517)` 筛负样本（未查 tier 列）：
**959 个 Tier-2**（train 495/val 161/expl 303）进入"困难"集——
它们的 kin ∈ (0.35, 0.6517]（**已明确未过空间门控**却因错误阈值
混入）；且 555 缺失 + 17 错框进一步扭曲运行时集合。

## 2. 修复

`margin(rowset, key, tier)` 严格按 `hard_negative_tier == tier`
筛负样本；Tier-2 与 all-gated **独立分列**。

## 3. 新基线（固定查询协议 + 规范框 + 纯 Tier-1）

|---|---|---|
| **B0 静态 Tier-1** | **0.0594** | **0.0497** |

| B0 Tier-2（独立） | 0.1900 | — |

**关键判读**：
1. Tier-2 margin（0.19）远大于 Tier-1（0.059）——**证实旧 M_hard
   被 Tier-2 污染压低**（旧 B0 0.0333 vs 纯 Tier-1 0.059——
   旧值低估了真实判别力但仍作废）；

   纯 Tier-1 竞争下预测特征更弱（与 J2.3 诊断一致）；
3. **新 D4 预注册判定标准：val Tier-1 M_hard > 0.0594（B0 新基线）**
   （旧 0.0333 正式作废——审计要求 ✓）。
