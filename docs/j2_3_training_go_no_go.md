## 1. 十三问回答

1. **遗留接口漏洞修复？** 是——①非 accept 决策**不再提交**
   chosen_identity（倾向身份分离到 tendency_identity 字段）；
   ②run_j2_2_association 的三处 `thr or default` 零阈值替换改为
   显式 None 检查；27/27 回归固化；
2. **B4 均值化/低多样性？** **是（强证据）**——PR 18.25→6.46、
   mean-dir 0.692→0.845、通道方差减半、B2→B4 越学越集中；
3. **区分下降的样本表现？** 全局性（同向漂移：same 与 hard
   cos 同升；非 gap 特有、非遮挡特有）；
4. **协方差正则的实验动机？** 存在但**不单独充分**（常量反例：
   塌缩表示 cov=0）——作 D4 之后的独立消融；
5. **Tier-1 时空竞争负样本量？** 391/412 序列（95%）、帧级
   119,081、Tier-2 actor 1,741；
6. **覆盖遮挡/外观相似/长间隙？** gap 三档均衡（128/142/130）；
   遮挡由 occ 标签携带、外观相似由特征空间携带（分层字段全）；
7. **Visibility Memory 改善关联？** 轻微（V2/V3 M_hard 0.074→
   0.085）；V1≈V0——**H3 弱**，保留为可选模块不进主训练；
8. **支持训练 Actor-Conditioned Query？** **是**——H1+H2 主导
   证据 + Tier-1 素材就绪 + 判定标准预注册（M_hard > 0.112）；
9. **Teacher-Student 非对称扰动必要？** 现在不必要（H3 弱 +
   池化特征不满足 Copy-Paste 前提）——准入条件已写（patch tokens）；
10. **数据泄漏/标签不可靠残留？** 已知路径为零（G0 契约修复 +
    J2.1/J2.2 协议继承 + 本轮零重划分）；
11. **最有希望的下游模块？** **判别 Query（D4）**——直接对齐
    "历史证据→目标条件化关联表示→竞争辨识→不确定性传递→事件
    可信验证"链路；Visibility Memory 为次（审计价值>性能价值）；
12. **允许进入下一轮正式训练？** **允许（受控）**——见下。

## 2. 最终判定：**GO（受控训练 D4）**

J2 历经 v1（0.110）→v2.2 残差+扩充（0.189）两轮负结果后，
**本轮诊断首次给出可执行的因果链**：共性化（H1）+ 目标不一致
（H2）→ 判别排序目标是最小充分改动。

**GO 内容（下一轮唯一训练项）**：
D4 = B4 残差架构 + Tier-1 hard-negative ranking（λ 单变量），
对照 B4/B0 同协议；**判定标准：val M_hard > 0.112（静态基线）**，
未达标则保留第三轮负结果（不再调参翻找）。

**CONDITION（启动前）**：Tier-1 采样器实现真实时间重叠过滤
（帧级 119k 对需按竞争集组织）+ 训练中 M_hard 早停监控。

**NO-GO**：D5 协方差（待 D4 结果）、D6 扰动（准入未满足）、
Teacher-Student、事件级实验（人工真值未完成——三轮一致）、
完整 OccuSolver/CoTracker。
