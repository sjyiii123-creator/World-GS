# J1.1 帧对齐审计（JAAD XML ↔ SynPeDAS 真实视频）

日期：2026-11-05 | 方法：全量结构核验（211）+ 独立图像-标注 IoU 证据
核验（E1 十样本，双映射对照）。模型未查看任何图像——IoU 为纯数值计算。

## 1. 映射约定（受审对象）

`build_actor_sequences.py` / `latent_features.py` 采用
**M1：video_frame = xml_frame − window_start**（窗口起点来自 sample_id
的 `f<start>-<end>` 声明）。

## 2. 全量结构核验（211 样本）

| 检查项 | 结果 |
|---|---|
| MP4 实际帧数 == f1−f0（窗口长） | 210/211 ✓ |
| 目标行人 XML 帧范围 ⊆ [f0, f1) | 210/211 ✓ |
| **唯一异常** | **0037**：视频 300 帧@59.94（≠窗口声明 150）；XML 全范围 [0,237] |

## 3. IoU 图像证据核验（E1 十样本，双映射对照）

方法：每样本取目标行人全部 XML 帧，分别按 M1（xml−f0）与 M2（xml 直用）
映射到视频帧，与 v3.1 的真实检测框（同帧 person 检测）计算最大 IoU。

| 样本 | f0 | M1 IoU（匹配帧数） | M2 IoU | 结论 |
|---|---|---|---|---|
| 0002 | 60 | **0.706**（150/158） | 0.000（98） | M1 ✓ |
| 0020 | 381 | **0.765**（125/506） | 0.005（150） | M1 ✓ |
| 0024 | 60 | **0.891**（1） | 0.0（1） | M1 ✓ |
| 0044 | 60 | **0.846**（150/210） | 0.006（150） | M1 ✓ |
| 0003/0016/0027/0030/0035 | 0 | 0.69–0.84 | 同 M1（f0=0 两映射恒等） | M1 ✓ |
| **0037** | 0 | **0.755**（230/238） | 同 M1 | **M1 ✓** |

**判定**：M1 映射在全部 10 个有独立检测证据的样本上成立
（f0>0 的 4 个样本 M1 完胜 M2：IoU 0.71–0.89 vs ≈0）。

## 4. 0037 的定性（不构成映射错误）

- f0=0 → M1 与 M2 恒等；IoU 0.755（230 帧匹配）**直接证实**
  `video_frame = xml_frame` 正确；
- 其异常是**窗口声明标签失实**（声明 [0,150) 但视频为完整 300 帧
  clip，行人 XML 帧到 227）；
- 对 J 系列的实际影响：`build_actor_sequences` 以 [f0,f1) 过滤 XML
  观测——0037 的行人帧 150–227 被**保守截断**（数据量减少，
  已用样本的正确性无损）；特征读取帧号正确；时间戳用
  manifest real_fps=59.94 ✓ 正确；
- 处置：**保留过滤 + 显式标记**（数据集 meta 已含窗口协议；
  本审计建立 `window_claim_mismatch` 清单——仅 0037 一例）。
  可选后续：扩展 0037 窗口至 [0,300) 重建以利用完整观测（不影响
  既有结论，属数据增量）。

## 5. 结论

1. **M1 映射核验通过**：结构 + 图像证据双通道一致；
2. **0037 为窗口声明失实，非映射错误**；且 0037 未进入 J1 测试子集
  （J1 的 800 test 对不含 0037 的 pair——任务书已知事实，
  经 pair_results 样本去重核验属实）；
3. 因此 **J0/J1 已有结果的数据基础有效**——不宣称失效，
  也不宣称"全部视频永远无映射问题"（核验是证据性的，非穷尽性
  断言；后续新样本沿用本协议复检）。
