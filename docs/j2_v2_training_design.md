# J2 v2 训练设计（不立即训练——设计 + 单元测试 only）

日期：2026-11-05 | 前提：J2 v1 负结果在公平复核后成立
（区分间距 0.11 vs 0.26；hard 负样本 0.686 vs 0.557；训练量
160 独立 actor 是首要嫌疑）

## 1. 候选设计（A/B/C/D——B/C/D 本轮只设计不运行）

| 设计 | 内容 | 针对 v1 的哪个失败 |
|---|---|---|
| A 原始 GRU | v1 复现基线（全量数据重训） | 训练量不足假设的直接检验 |
| **B Static Residual** | 预测目标改为 **Δ特征 = target − anchor_last**；预测器输出残差，静态末帧 + 残差 = 预测 | **共性化**：残差目标迫使模型学"变化量"而非收敛到均值解；静态部分保底（残差≈0 时退化为 J2-A） |
| C B + Hard-Negative Ranking | 损失 = cos(pred, target) + λ·max(0, m − cos(pred,target) + cos(pred, hard_neg)) | 区分间距（0.11）而非预测 cos——直接优化判别目标 |
| D B + 2D 运动状态 | v1-D 的运动输入在残差框架下重做 | 长 gap 漂移（未兑现的假设） |

**残差假设的机理**：v1 的 GRU 输出收敛到"对一切 actor 都中等
相似"的均值化解（训练目标本身漂移大）。残差参数化把任务的
"简单部分"（外观近似不变）交给静态特征，模型只需学漂移修正
——共性化解在残差空间退化为零输出（安全退化），而 v1 中它
退化为"平均脸"（有害）。

## 2. 关键设计决策（预注册）

- **Hard negative 构建**：同源不同 actor 的候选观测（identity
  mask 已修复）——每个训练步采样 1 个同场景竞争者；
- **正负身份确定**：(source_video_id, actor_id) 相等——跨视频
  同数字 ID 不同人；
- **候选时间处理**：训练时目标 = 真主首观测（监督合法）；
  推理/评估时每候选独立 delta（Gate 1 协议）；
- **共性化检查**（训练中监控）：a) 预测特征批内方差；
  b) cos(pred, batch 均值特征)——若 pred 趋向均值则该值→1；
  c) 区分间距作为早停指标（不只 val loss）；
- **防泄漏**：forward 只收 (history, delta)；`predict_is_causal`
  守卫 + 数据构建双通道核验（v2 已 0 违规）；
- **训练预算**：全量 A 正对（~7,920，扣除重复 anchor 后
  ~2,600 独立单元）× 40 epochs ≈ 分钟级 GPU（v1 实测 1s/epoch
  外推）；单卡 0.05GB 无压力。

## 3. 纪律

- 不得一次加入所有损失（B 先行独立验证 → C 在 B 显示残差有效
  后引入 → D 最后）；
- 判定标准沿用 J2.1 修正协议（区分间距 + 竞争集 A3 对照），
  **训练损失不作为成功标准**；
- 全量重训前先在 v2 412 序列上过拟合检查（六步梯第 5 步协议）。
