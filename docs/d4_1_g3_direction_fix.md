# D4.1 G3 方向修复报告

日期：2026-11-06 | 修复：kin 排序方向 + 联合评分公式

## 1. 确认缺陷

`run_d4_eval.py::selective()` 对 kin（距离）执行 **降序** 排序：
`key=lambda c: -c["kin"]`——`ranked[0]` = **最大误差候选**。
后果：A1 的 wrong_50 = 1.0（全部接受的都是错误身份）。

## 2. 修复

| 项 | 旧 | 新 |
|---|---|---|
| kin 排序 | `-c["kin"]`（降序=最差优先） | `c["kin"]`（升序=最佳优先） |
| 相似度排序 | `-c[score]`（降序=最佳优先） | 不变（正确） |
| 联合评分 | `kin * cos`（乘积，方向不明） | `-kin + cos`（线性组合，可翻转 top-1） |

## 3. 修复后实测（val 60 anchor）

|---|---|---|---|
| A1 (kin) | 0.650 | **0.2667** | 审计精确值 8/30 ✓ |

## 4. 结论

- A1 wrong_50 = 0.2667（8/30）——**与独立审计精确值一致**；
- D4 联合 top-1 = 0.700（42/60）——**超过 A1 的 0.650**；
- D4 联合 wrong_50 = 0.2667 = A1——**在相同覆盖率下，联合评分不劣于 A1**；
- 但 **D4 联合 wrong_50 并未优于 A1**（同为 0.2667）——选择性增益为零。
