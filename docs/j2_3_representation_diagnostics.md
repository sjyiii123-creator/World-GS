## 2. 三假设裁决（按任务 §四判定规则）

**H1（预测表示共性化）——强支持**：
- PR **18.25→6.46**（预测集中到 ~6 个主方向 vs 静态 18 个）；
- mean-dir 0.692→0.845（更靠公共均值方向）；
- 通道方差减半（1.39e-3→7.6e-4）；
- **B2→B4 的 PR 下降轨迹**（16.6→6.5）：数据越多模型学得越多、
  学到的越偏公共方向——容量被用在共性解上；
- 常量反例成立：塌缩表示的协方差损失=0——**协方差正则的动机
  存在但单独不足**（需与判别目标并用）。

**H2（训练-任务目标不一致）——中强支持**：
- B4 的 same 0.780 **最高**（回归能力真实存在）但 hard 0.653
  同升——正负相似度**同向漂移**：模型优化的是"像一切未来行人"
  而非"区分这个与那些"；
- Tier-1 真实竞争素材已就绪（G2：391/412 序列有空间门控
  竞争者）——判别训练的数据条件满足。

**H3（遮挡参考污染）——弱支持**（G3 见 visibility 报告：
V1≈V0，anchor 末帧多为可见帧；V2/V3 多帧聚合 +0.011 M_hard）。

## 3. 结论

负结果的归因排序：**H1+H2（表示共性化 + 判别目标缺失）为主**，
H3 次要。下一轮训练的最小改动应是**判别排序目标**（正对
Hard-Negative margin 直接优化），协方差正则可作为其**后的独立
消融**（GOT 文献对齐文档 §1）。
