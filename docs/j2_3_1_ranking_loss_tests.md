# J2.3.1 排序损失符号修复与测试

日期：2026-11-05 | 实现：`wmeval/latent_world_state/ranking_loss.py`
测试：`selftest_ranking_loss.py` **7/7**

## 1. 符号错误确认

J2.3 设计文档公式 max(0, m + s⁺ − max s⁻) **方向反了**——它惩罚
正确候选得分高于负候选（优化方向与任务相反）。
**勘误：L_rank = max(0, margin + max_j s_j⁻ − s⁺)**。
**错误公式从未用于训练**（D4 未启动——设计阶段即被独立审计发现）。

## 3. 边界语义（预注册）

- 多正候选：调用方指定唯一正分（同身份重复序列是**采样器契约**
  ——绝不入负集，tier manifest 按 (src,actor) 键保证）；
- 无负批次：显式 detached 零（不静默 nan/带梯度零）；
- hardest-negative 聚合：max（非均值）。
